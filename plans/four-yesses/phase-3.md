# Phase 3 — the UI is ready to ship to 2,000

Tasks for `plans/four-yesses.md` Phase 3. Design-first: nothing with a visible
shape is built before its mock is approved in the conversation, with
screenshots. Written 2026-09-11 from a survey; every path named exists.

**State on 2026-09-11.** The Folders screen exists (f3497e9, 2026-09-05:
conversation streamed through a token, one tree keyed by term id, the Rules
tab, Move in three states with Stop and undo) and is covered by
`tests/ui/folders.spec.mjs`. What awaits approval is the **ways-in** mock,
`docs/superpowers/mocks/2026-09-10-folders-ways-in.html`, for the spec
`docs/superpowers/specs/2026-09-10-folders-ways-in.md`. The nine screens are
`core/admin-shell.php`'s list: Dashboard, Folders (`media-librarian`), AI,
Duplicates (`media-health`), Import folders, Licence, Taxonomies, Library
settings, File types. Every push screenshots them (`tests/ui/shots.spec.mjs`).
`ROW_ALARM = 300` in `tests/ui/modes.spec.mjs` guards the list row height.
The tree component (`js/vergeml-tree-view.js`) already has `role="tree"`,
`treeitem`, `aria-level/posinset/setsize/selected`, `aria-expanded` and a
`keydown` handler on the list. No translations exist (`languages/*.pot` only).
No axe package is installed. RTL sheets: 11, generated by `tools/rtl.mjs`.

**Model.** 3.1, 3.5, 3.8, 3.9, 3.11, 3.12 — Opus 5. 3.2–3.4 — Fable 5.1 in
one session after 3.1's approval (an app shell, a shared component's rows, two
parsers: architecture and a shared component). 3.6, 3.7 and 3.10 — design on
Opus (a mock with the copy, approved), build on Fable (3.7 and 3.10 touch
every screen or a shared widget).

**Sessions.** S1: 3.1. S2 (Fable): 3.2 + 3.3 + 3.4. S3: 3.5 + 3.9. S4: 3.6
design. S5 (Fable): 3.6 build + 3.10. S6: 3.7 design (the eighteen states,
with copy). S7–S8 (Fable): 3.7 build. S9: 3.8 + 3.11. S10: 3.12 protocol;
the sessions with strangers are Nathan's.

**Stop points (Nathan).**
