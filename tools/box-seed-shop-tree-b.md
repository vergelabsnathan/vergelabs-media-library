A tree the fixture's author did not write: HEMA's public category tree
(hema.nl/sitemap and its department pages, read 2026-09-17), 292 folders,
three levels where the shop has them, the names exactly as the shop writes
them, the marketing folders kept (nieuw, sale, aanbiedingen, nieuwe
collectie, fotoservice). Dutch against an English describer: the names say
nothing a picture says, which is what the story measures.

Use: on ms2, Unconfirm, remove the tree (the undo or a tree restore), upload
this file on the Folders screen, read the confirm's cost on the button (the
parents and the top level go to the planner — Dutch names are in no
picture's words, so ~125 go: three batches, 100 free, ≈ 5 credits; say it
before the press), confirm, Fill. No describes. Then
`node tools/filing-baseline-check.mjs --library shop --retake "<reason>"`
into a second band file and the dry sheet with `VGML_SITE=shop`.
