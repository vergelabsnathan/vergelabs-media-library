The row is not tall because there are thirteen columns. It is tall because everything in it wraps at a character a line, and the biggest single thing is core's own .row-actions — Edit · Delete · View · Copy URL · Download — which core hides with position: relative; left: -9999em. Relative keeps it in the flow, so at 42px wide it wraps to 1,153px and sets the height of every row. Removing all four of our columns changes the row by nothing; removing FileBird's pane as well still leaves 348px.
