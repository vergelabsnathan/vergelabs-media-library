Files you have taken out of the library

Setting a file aside takes it out of your media library without touching the file itself — same file on the server, same web address, still working on every page that uses it. If something you had forgotten about was using it, nothing breaks and you find out. Nothing can even be considered for deleting until 30 days have passed, and this plugin never deletes anything: when the wait is over it hands you a list and the rest is up to you.
